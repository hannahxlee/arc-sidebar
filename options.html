Finish setting up ⌘⇧C for Copy URL

Chrome uses ⌘⇧C for DevTools, so it didn't let the extension take it automatically. You can claim it yourself in three steps.

  1. Click Open Chrome's shortcut settings below.
  2. Find hannah's hub → Copy the current tab's URL and click the pencil icon.
  3. Press ⌘⇧C. Chrome then gives the shortcut to the extension instead of DevTools.
Pressing ⌘⇧C in that field opens DevTools or doesn't record?

Set the shortcut from the console instead.

  1. Open chrome://extensions. Chrome doesn't allow extensions to open this page for you.
  2. Press ⌥⌘J to open the console.
  3. Paste the line below and press Return.

Tabs

      
      
When you open a new tab (⌘T) and go to a page that's already open, the new tab closes and Chrome switches to the existing one. Click Open in new tab in the message that appears to open it separately.

    


    

      
Chrome vertical tabs

      
Turn on Chrome's vertical tabs by right-clicking the tab strip and choosing Show tabs vertically. With this option on, the sidebar works together with Chrome's tab list.

      
      
    
        
  • Favorites become pinned tabs. Pinning a tab in Chrome adds it to Favorites, and unpinning removes it.
    • 
        
  • Folders become tab groups with the same name. Dragging a tab into a folder's group adds it to the folder, and dragging it out removes it. Renaming or recoloring the group updates the folder.
    • 
        
  • PRs opened from the sidebar collect in a "Pull Requests" group.
    • 
        
  • The sidebar's Today list still shows all your open tabs that aren't in a Favorite or folder.

GitHub pull requests

      
Create a classic personal access token with the repo and read:org scopes. A fine-grained token with read access to pull requests also works, but only for the repositories it covers. The token stays in this browser's local extension storage and is only sent to api.github.com.

      
      

      
      
    


    

      
Browser-wide shortcuts

      
These work everywhere, including on new-tab and chrome:// pages, even when the page has focus. Chrome manages them, so change them on Chrome's shortcuts page. ⌘⇧C copies the current URL by default.

      

      
    


    

      
Custom in-page shortcuts

      
Bind any key combination to an action. These run on regular web pages. They don't run on chrome:// pages, the Chrome Web Store, or when the address bar has focus. Click a shortcut, then press the new keys. Press Esc to cancel or Backspace to clear.
